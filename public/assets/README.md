# Assets Directory

Place your personal files in this directory:

1. **`photo.jpg`**  
   Your personal profile portrait picture.  
   It is displayed on the **Home** and **About** pages. If you haven't added it yet, the site automatically falls back to `assets/photo-placeholder.svg`.

2. **`resume.pdf`**  
   Your official resume PDF.  
   The **Resume** section's "Download PDF" button directly links to this file (`assets/resume.pdf`).
